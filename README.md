# Trichodesmium 0.8.0

Промежуточный локальный прототип: фотографии → кандидаты B → HTML, PNG и CSV/XLSX.
Все определения и маски требуют визуальной проверки. Вид и число клеток не определяются.

## Основной запуск

Готовая Linux-сборка не требует установки Python. Распаковать всю папку,
сохранить `_internal` рядом с исполняемым файлом:

```bash
./trichodesmium "/путь/к/фото" -o "./results/run-001"
xdg-open "./results/run-001/index.html"
```

Из исходников (Python ≥3.10):

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m trichodesmium "./photos" -o "./results/run-001"
```

Основные команды `trichodesmium`, `trichodesmium-local` и `python -m trichodesmium`
теперь запускают только B. A удалён из текущего кода, история сравнения сохранена
в ветке `compare-tubular-masks`. `trichodesmium-seeds` — отдельный диагностический
первичный детектор, не итоговая морфометрия.

## Изменения 0.8

- Любой контейнер (включая HEIC) декодируется один раз в RGB8; детектор работает
  после нормализации ширины до 960 px. Преобразование и исходный размер записаны.
- Калибровка использует отдельный растр шириной до 1920 px и переносится в
  исходные/рабочие координаты. Данные шкалы переиспользуются между окнами.
- Совместимые по направлению и ширине концы разных фрагментов связываются.
  При двух равноценных продолжениях узел остаётся неопределённым.
- Длинные плавные маршруты получают больший приоритет; дублирующие короткие
  оси подавляются. Разрывы ткани не заполняются измеренными пикселями.
- Контраст B считается на локальной вырезке, а не многократно на всём кадре.
- `L оси` включает всю прослеженную линию до видимых концов маски; соединения
  через перекрытия — оценка, показанная штрихом. `L видимого` отдельно показывает
  реально поддержанные участки. Невидимая длина вынесена в отдельные столбцы.

## Результат

`index.html` → `report/index.html`: фото по порядку, исходник → разметка →
измерение каждого прошедшего фильтр кандидата. Пустые кадры и ошибки различаются.
`B-measurements.xlsx` / `.csv` содержат видимую и прослеженную длины, ширину маски,
калибровку и статус. CSV UTF-8 BOM, разделитель `;`.
`report/png-report` содержит сводные PNG. `report/diagnostics.html` содержит
диагностику только B. В `report/manifest.json` — параметры, исходники, геометрия,
соединения, декодирование и время каждого этапа.

Ширина маски не является независимо проверенной шириной клеток.
`L оси` не доказывает принадлежность всех участков одной биологической нити.
Общие маршруты нельзя автоматически суммировать для биомассы.
Короткие/слабые нити могут пропускаться; посторонние длинные объекты могут
попадать в кандидаты. На новом наборе пока остаются пустые кадры.

## Шкала и ввод

Поддержаны JPG/PNG/HEIC/HEIF/TIFF/BMP. Для подпапок — `--recursive`.
Сохранён исходный файл. HEIC: главный кадр, поворот/отражение, ICC→sRGB,
RGB8 без HDR-карты; PNG-предпросмотр. Пересохранение RGB в PNG само по себе
не меняет результат; отличия цвета/кадрирования/разрешения могут его менять.

Малое деление 3 мкм, вся шкала 600 мкм; видимая часть не считается всей шкалой.
Без уверенной калибровки остаются px. Ручной масштаб должен относиться к
исходному пикселю: `--scale-mode manual --um-per-pixel ЗНАЧЕНИЕ`.
Референс: `--scale-mode reference --reference ФАЙЛ --reference-points X1 Y1 X2 Y2
--reference-distance-um ДИСТАНЦИЯ`. Одинакового объектива недостаточно для
переноса масштаба между произвольно обрезанными фото.

Git-репозиторий локальный, `.git` включён в архив исходников. GitHub не подключён.
