# Trichodesmium 0.7.0 — запуск на CachyOS / Arch Linux

Это готовая переносимая сборка Linux x86_64. Python, HEIC-декодер, модели и
русский шрифт включены. Интернет, установка Python и GPU для обработки не нужны.
Запуск — из терминала; отдельного графического окна пока нет. Отчёт открывается в браузере.
Нужна glibc 2.39 или новее. Сборка проверена на Linux x86_64 с glibc 2.39;
на самом ноутбуке с CachyOS ещё не запускалась.

## 1. Распаковать и открыть папку

Скачай `trichodesmium-0.7.0-linux-x86_64.tar.gz` и распакуй весь архив.
Не вынимай исполняемый файл отдельно: папка `_internal` должна остаться рядом.
Можно распаковать через файловый менеджер или из терминала:

```bash
tar -xf trichodesmium-0.7.0-linux-x86_64.tar.gz
cd trichodesmium-0.7.0-linux-x86_64
./trichodesmium --version
```

Должно появиться `0.7.0`. Команды одинаковые для bash и fish.

## 2. Первая проверка на приложенном фото

```bash
./trichodesmium "./example-photos" -o "./results/demo-001"
xdg-open "./results/demo-001/index.html"
```

В `example-photos` лежит исходное фото 13 из нашей выборки. На нём ожидается
кандидат основной диагональной нити и измерительные линии. Нижний короткий
фрагмент алгоритм может пропустить — это известная ошибка прототипа.
Точные числа смотри в таблице собственного запуска; они относятся к маске.

Если `demo-001` уже существует, выбери `demo-002`. Результаты не перезаписываются.
`xdg-open` нужен только для открытия отчёта; можно открыть `index.html` вручную.

## 3. Проверка собственных фотографий

Положи оригинальные JPG/PNG/HEIC/HEIF/TIFF/BMP в отдельную папку. Например:

```bash
./trichodesmium "/home/ТВОЙ_ПОЛЬЗОВАТЕЛЬ/Pictures/Trichodesmium" -o "./results/local-001"
xdg-open "./results/local-001/index.html"
```

Замени путь в кавычках своим. Или запусти `./trichodesmium` без аргументов:
программа спросит путь к папке и сама создаст новую папку `results/run-...`.
Для подпапок добавь `--recursive`. Несколько TIFF-страниц нужно заранее
сохранить отдельными фотографиями. Оригинальные HEIC читаются напрямую.

## 4. Что программа сейчас выдаёт

Один запуск проходит два этапа: исходные цветовые кандидаты и уточнение
вариантом B. Основной результат — именно B, он не ограничивает число кандидатов 1–3.

- `index.html` открывает основной B-отчёт.
- `report/index.html`: фото по порядку, исходник → разметка каждого кандидата
  → отдельная картинка измерений. При пустом результате написано «Ничего не найдено».
- `report/png-report/*.png`: по одному последовательному PNG на каждое обработанное фото.
- `annotation.png` и `measurement.png` в папках осей: отдельные изображения кандидата.
- `B-measurements.xlsx` и `B-measurements.csv`: строки кандидатных осей B,
  длина поддержанных участков, средняя ширина маски, px/мкм и статус проверки.
  CSV в UTF-8 с BOM и разделителем `;`; XLSX открывается в LibreOffice Calc.
- `run-info.json`: итоги и ошибки файлов. `report/manifest.json`: параметры,
  калибровка, версии, хеши фото, модельные оценки и геометрические линии.
- `report/comparison.html`: дополнительное сравнение A/B, отбраковки и варианты.
- `seed-report`: первоначальный детектор, исходные маски и редактор исправлений.
  Его таблицы — диагностика первого этапа; для B используй `B-measurements.*`.

Красный контур — гипотеза. Голубые отрезки — ось, по которой считается длина.
Жёлтые поперечники — сечения, по которым считается средняя ширина маски.
Шкала и неоднозначные общие узлы исключаются из измеренных частей.
Длина — сумма поддержанных отрезков оси; скрытые промежутки не дорисовываются
как измерения. Ширина маски ещё не является проверенной внешней шириной клеток.

Мкм появляются при доступной калибровке. Известно: малый интервал 3 мкм,
полная шкала 600 мкм. Видимый кусок шкалы не растягивается автоматически до 600.
Масштаб читается для каждого фото; фото разного разрешения не смешиваются
при проверке согласованности. Если масштаб не найден, остаются px и явная пометка.

## 5. Что пока может быть неправильным

Это промежуточный прототип. Возможны пропуски слабых/коротких нитей,
лишние окрашенные помехи и неверные маршруты в пересечениях. Один трихом
может получить несколько осей, а общие маршруты могут дублироваться.
Строки таблицы нельзя автоматически суммировать для расчёта биомассы.
Вид, число клеток, длина клетки и полная скрытая длина цепи не определяются
в основной B-таблице. Число осей не равно доказанному числу трихомов.

Первый детектор настроен на прежних снимках 960×1280. Новые HEIC с другим
освещением/разрешением требуют проверки результата. Они читаются в исходном
разрешении; B использует рабочую ширину 960 px, а пересчёт мкм учитывает это
преобразование. Анализ RGB8; исходный HEIC сохранён, встроенный ICC переводится
в sRGB, HDR-карта не используется. Предупреждения декодирования есть в JSON.

## 6. Если автоматический масштаб не найден

Задавать ручной масштаб стоит только после собственного измерения шкалы.
Например, если проверено, что он равен 0.79 мкм на исходный пиксель:

```bash
./trichodesmium "./photos" -o "./results/manual-001" --scale-mode manual --um-per-pixel 0.79
```

0.79 — пример, не универсальный масштаб всех файлов. У HEIC другого
разрешения значение может отличаться. Можно использовать референс:

```bash
./trichodesmium "./photos" -o "./results/reference-001" --scale-mode reference --reference "./scale.HEIC" --reference-points 100 200 500 200 --reference-distance-um 300
```

Координаты и 300 мкм здесь тоже пример: поставь точки и реальную известную
дистанцию. Референс переносится только при совпадении размеров и оптического/
цифрового масштаба. Отдельный объектив сам по себе этого не гарантирует.

## 7. Если запуск не получился

- `Permission denied`: в распакованной папке выполни `chmod +x ./trichodesmium`.
  Если папка находится на диске с запретом запуска, перенеси её в домашнюю папку.
- Ошибка `GLIBC_... not found`: сборке нужна glibc ≥2.39. Скопируй полный текст
  ошибки и вывод `ldd --version`; потребуется совместимая пересборка.
- Не найдена библиотека/`_internal`: распакуй весь архив, не только файл программы.
- «Папка результата уже существует»: измени имя после `-o`.
- Ошибка конкретного фото: остальные кадры обрабатываются, подробности в JSON.
- Не запускай программу через `sudo`: ей нужны права только на чтение фото и запись отчёта.

Программа пишет прогресс в терминал. Обработка больших HEIC может потребовать
значительно больше времени и памяти; сначала попробуй 1–3 фото.
Системная команда `time` перед запуском поможет измерить время на твоём ноутбуке.
Код возврата 0 — отчёт создан; 1 — есть ошибки отдельных файлов; 2 — неверный
вход/параметры или невозможность запуска. Пустой результат/неизвестный масштаб
сами по себе не объявляются доказательством отсутствия организмов.
