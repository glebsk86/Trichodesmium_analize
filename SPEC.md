## Зафиксировано

- macOS и Linux; локальный запуск на CPU, Python 3.10+.
- Вход — директория фотографий разбавленной пробы, обычно отдельные трихомы.
- Объектив один и тот же. Цена малого интервала шкалы: 3 мкм.
- Полная шкала: 600 мкм = 200 интервалов. Между соседними рисками один интервал.
- Пиксельный масштаб определяется на каждом снимке, независимо от размера файла.
- Режимы масштаба: автоматический по рискам, общий ручной мкм/пиксель,
  референс с автоматической или двухточечной калибровкой.
- Краткая таблица: строка на объект; фото/ID, вид, ширина (мкм), длина
  цепи (мкм), длина клетки (мкм), число клеток.
- Подробные таблицы по фото: пиксельные/физические измерения, масштабы,
  причины сомнений, методы подсчёта, отдельные измерения клеток и ширины.
- Необязательные вырезки, маски, разметка всей фотографии и объекта.
- Пять целевых видов: clevei, thiebautii, hildebrandtii, radians, erythraeum.

## Определения

Длина цепи — длина центральной линии видимой части. Включает изгибы,
не восстанавливает закрытые и невидимые фрагменты. Ширина — средняя длина
поперечных пересечений маски на пригодных участках центральной линии.
Длина клетки — среднее расстояние между кандидатными перегородками.
Число клеток в этой версии — только явно отмеченная оценка L/l;
автоматический прямой подсчёт пока не считается проверенным.
Обрезанный кадром трихом — видимый фрагмент; оценка числа клеток относится
только к нему. Недоступные величины остаются пустыми, а не равными нулю.

## Первая реализация

1. Экспериментальное выделение вытянутых объектов классическими методами.
   Это кандидаты: программа ещё не отличает надёжно триходесмы от других нитей.
2. Поиск длинных осей шкалы и повторяющихся рисок вне их центральной линии.
   Автоматическая калибровка сохраняет диагностические профили и маску шкалы.
   Размер 600 мкм хранится как контрольная справка; автоматический поиск обоих
   физических концов всей линейки не реализован. Не растягивать фрагмент до 600.
3. Центральная линия и поперечные ширины; сложные разветвлённые маски
   сохраняются для проверки, суммарная длина цепи для них не выдаётся.
4. Поиск кандидатных перегородок по профилю интенсивности. Случайная периодическая
   текстура тоже может давать пики; все такие результаты требуют ручной проверки.
5. Виды остаются «не определён». Размеров недостаточно для внедрения
   достоверного классификатора без размеченных данных и диагностических правил.
6. Отдельный вход для исправленных пользователем масок; маски могут содержать
   целочисленные ID отдельных объектов, поэтому пересечения можно исправить вручную.
7. Баллы/проценты вероятности не выдаются. Качество: средняя/низкая/не определена,
   с основаниями. Все объекты помечены как непроверенные кандидаты.

## Критерии дальнейшей проверки

Проверить 3–5 исходных снимков (хорошие/размытые/пересекающиеся), затем отдельную
выборку. Сравнить масштаб, длину и ширину с ручными измерениями; отдельно
проверить ложные объекты, пропуски и перегородки. Для каждой ошибки хранить
исправления. Отчёт записывает версию программы, Git-коммит, зависимости,
параметры и SHA-256 источника. Это обеспечивает воспроизводимость,
но само по себе не доказывает точность биологических результатов.

## Реализация 0.2: первые фото и исправление результатов

Для серии 960×1280 добавлен именованный экспериментальный профиль
`microscope-20261002`, настроенный на всех шести присланных снимках.
Его приблизительные штрихи не являются экспертными масками, а выделение
пигментированной сердцевины не гарантирует полную внешнюю границу нити.
Профиль записывается вместе с хешем модели и предупреждениями в отчёт.
Число кандидатов алгоритмически не ограничивается 1–3.

Галерея `index.html` отдельно показывает RGB-фото, разметку и техническую
маску. Редактор содержит исходное фото, раздельные ID, кисть, ластик,
отмену и экспорт PNG. Результат не сохраняется до скачивания PNG. Импорт
`--mask-format instances` сохраняет один ID даже у разрозненных частей;
разрыв не заполняется и единой длины у такого объекта нет. При пересечении
в редакторе один пиксель принадлежит последнему нанесённому ID; скрытые части
не дорисовываются как измеренные.

На автоматических масках допускается игнорирование коротких ответвлений
скелета до локальной толщины, но не более 12 пикселей, с явным флагом.
Длинные ветви/пересечения по-прежнему дают отказ от одной длины.

## Реализация 0.3: локальный цвет и поддерживаемые фрагменты

Новый профиль `microscope-colour-20261005` использует двусторонний локальный
цветовой контраст в Lab и парные тёмные края. Старые деревья и данные их
обучения сохранены без переобучения. Слабые цветные участки дополняют семена;
кривые нити не отбрасываются только из-за малого отношения осей PCA.
Близкие фрагменты могут получить один предположительный ID, без заполнения
промежутков в измерительной маске. Это не восстановление скрытой цепи;
разрывы и разветвления сохраняют отказ от единой длины. Внешние контуры,
принадлежность фрагментов и пропуски требуют ручной проверки. Настройка
использовала девять уникальных снимков, поэтому независимой валидации нет.
