# Проверка версии 0.2.0

Дата: 2026-10-02. Среда: Linux x86_64, Python 3.12, CPU.
На macOS и в окружении пользователя Python 3.14 проверки не выполнены.

`python -m pytest -q`: **37 проверок прошли**. Из них шесть используют
присланные фото из `data/user-six`, исключённые из Git. Если этих файлов нет,
шесть проверок пропускаются. Эти же фотографии использовались для настройки
и обучения профиля; **независимой валидации нет**.

## Исправления и проверка

- Фон с жёлтой окраской больше не считается целым цветным объектом.
  Чёрные края поля и JPEG-шум исключены из автоматического выделения.
- Глобальная заливка дырок удалена из общего детектора объектов.
- Отдельный профиль `microscope-20261002` использует 24 дерева OpenCV,
  локальные цветовые признаки и текстуру. Веса, приблизительные штрихи,
  код повторного обучения, хеши исходников и оговорки сохранены в проекте.
- На шести снимках проверяются сохранение явного участка главной нити,
  исключение чёрного окружения и отсутствие прежнего захвата всего поля.
  Это проверки регрессий на данных настройки, не оценка полноты выделения.
- Слабые мелкие риски шкалы читаются по спектру и отдельным интервалам.
  Известные интервалы 3,8 и 12 пикселей на размытых шкалах не подменяются
  кратным/половинным периодом. Сохранены проверки поворота, изменения размера,
  отказа без шкалы и отказа считать клеточные перегородки линейкой.
- Сохранены проверки измерения известной длины/ширины, поворота,
  неоднозначных масок, перекрытий, ручного и референсного масштаба.
- Короткие ответвления скелета можно игнорировать только в пределах
  локальной толщины и 12 пикселей, с флагом в отчёте. Длинное пересечение
  по-прежнему не получает одной выдуманной длины.
- Исходный RGB-кроп сравнивается с исходными пикселями по точному равенству.
  Галерея отдельно подписывает фото, разметку и техническую маску.
- Проверяются PNG с одинаковыми RGB-каналами, непрозрачной альфой,
  сохранение разорванных частей одного ID в режиме `instances`, ошибки
  размера, EXIF, повреждённые файлы и запрет перезаписи результатов.

Редактор дополнительно проверен исполнением его JavaScript с Canvas:
загрузка, рисование ID, отсутствие промежуточных ID от сглаживания, отмена,
ластик, экспорт PNG, очистка, восстановление. Сохранённый PNG прочитан
настоящим импортёром масок. Это не заменяет проверку интерфейса в браузерах
пользователя. Проверочный скрипт: `tools/check_editor.cjs`, необязательная
зависимость разработки `@napi-rs/canvas`; Node.js для обработки фото не нужен.

Всего **11 против 110** строк. Ни один алгоритм не ограничивает число
кандидатов тремя. Снижение количества не доказывает правильности:
остаётся существенный недобор видимых частей. Число строк нельзя считать
числом трихомов. Маски сердцевин не являются проверенными внешними контурами.
При разветвлении/разрывах физические размеры могут оставаться пустыми;
доступные размеры относятся к конкретной предложенной маске.

На этих шести фото калибровка теперь получена для всех кадров; в старом
отчёте для всех шести был отказ. Величины согласуются при одном объективе
и одинаковом разрешении, но не сверены с независимыми ручными измерениями.
Оба физических конца всей линейки 600 мкм не проверены.

## Следующая проверка

Исправить внешние контуры в `index.html` → «Исправить маску», сохранить PNG
и повторить обработку с `--mask-format instances`. Независимо измерить
несколько интервалов шкалы и подходящие нити. Новые фото отложить для
проверки после настройки на исправленных масках. Только после этого оценивать
ошибку длины/ширины, полноту/ложные находки и клеточные перегородки.
